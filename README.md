# Proyek AP17 · Komunikasi Lintas Media

Situs instruksi dan bahan tema untuk Proyek AP17 mata kuliah Komunikasi Lintas Media (DKV 6250), Universitas Prima Indonesia.

Situs: https://ilmanakbareffendi.github.io/klm-proyek-p8/

Materi tema bersumber dari CV Handbook UNPRI, Pusat Pengembangan Karir dan Kewirausahaan (CEDC) UNPRI.

## Menjalankan di komputer sendiri
1. Unduh atau clone repo ini.
2. Di folder repo, jalankan `python3 -m http.server 8000`.
3. Buka `http://localhost:8000`.

## Struktur
- `index.html`: beranda.
- `instruksi/`, `kelompok/`, `tema-a/` sampai `tema-e/`: satu folder per halaman.
- `assets/`: kode, gaya, huruf, ikon, dan logo bersama.
- `pdf/`, `qr/`, `video/`: bahan tema.
- `CLAUDE.md`: aturan kerja untuk alat AI dan programmer.
- `CHANGELOG.md`: catatan perubahan.
